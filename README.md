# 📞 Колл-центр MVP — Система управления персоналом

Полнофункциональная система управления сотрудниками, графиками смен и документами для колл-центра.

---

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- PostgreSQL 14+
- npm

---

### 1. База данных

```bash
# Создайте БД
psql -U postgres
CREATE DATABASE call_center_mvp;
\q

# Инициализируйте схему (первый запуск)
psql -U postgres -d call_center_mvp -f database/init.sql
```

---

### 2. Бэкенд

```bash
cd backend
cp .env.example .env
# Отредактируйте .env — укажите параметры БД

npm install
npm start
```

**Бэкенд запустится на:** `http://localhost:3002`

---

### 3. Фронтенд

```bash
cd frontend
cp .env.example .env
# Проверьте VITE_API_URL в .env

npm install
npm run dev
```

**Фронтенд запустится на:** `http://localhost:5173`

---

### 4. Первый вход

| Логин | Пароль |
|-------|--------|
| `admin` | `admin123` |

## 🔧 Полезные команды

### Проверка системы
```bash
cd backend
npm run check
```
Эта команда проверит:
- Подключение к PostgreSQL
- Наличие всех таблиц
- Наличие администратора
- Статистику пользователей
- Типы смен
- Переменные окружения

### Сброс пароля администратора
```bash
cd backend

# Сбросить на admin123 (по умолчанию)
npm run reset-admin

# Сбросить на свой пароль
npm run reset-admin myNewPassword123
```

**Примечание:** Этот скрипт можно запустить в любой момент, даже если сервер работает. Пароль будет сброшен мгновенно.

### Миграция БД (добавление новых таблиц без потери данных)
```bash
cd backend
npm run migrate
```

### Полная переинициализация БД (⚠️ удаляет все данные)
```bash
psql -U postgres -d call_center_mvp -f database/init.sql
```

## 📚 Документация

После запуска бэкенда документация доступна по адресу: **http://localhost:3002/docs**

Также доступна из интерфейса через кнопку **"📚 Документация"** в шапке (для всех ролей).

Документация включает:
- Руководство по установке и первому запуску

- Инструкции для администратора и сотрудников

- API эндпоинты с примерами
- Схема базы данных
- FAQ и решение проблем

## ✨ Функции

- **График смен** — месячный календарь с отображением смен прямо в ячейках (имя, время, цвет по должности)
- **Заявки на изменение** — сотрудники запрашивают изменения, администратор рассматривает
- **Уведомления** — реальное время, разделение на прочитанные/непрочитанные
- **QR-коды** — отметка присутствия через сканирование
- **Посещения** — сотрудники видят свои входы/выходы, администратор и модератор видят всех с поиском и фильтрами
- **Документы** — администратор и модератор создают разделы, загружают только PDF и выбирают доступ всем или конкретным сотрудникам
- **Задания** — администратор/модератор назначают задания, сотрудники предлагают свои; к задачам можно прикреплять файлы
- **Регистрация** — сотрудник устанавливает пароль самостоятельно, после чего сразу входит
- **Документация** — встроенная документация доступна всем ролям из шапки

## 📁 Структура проекта

```
├── backend/
│   ├── server.js              # Express сервер + маршруты
│   ├── logRegController.js    # Авторизация / регистрация
│   ├── adminService.js        # Управление сотрудниками, QR, статистика
│   ├── graficController.js    # График смен, уведомления
│   ├── documentsController.js # Загрузка документов
│   ├── tasksController.js     # Задания
│   ├── middleware.js          # JWT middleware
│   ├── db.js                  # Подключение к PostgreSQL
│   ├── uploads/               # Загруженные файлы (создаётся автоматически)
│   └── scripts/
│       ├── initDb.js          # Инициализация БД
│       ├── migrate.js         # Миграции (без потери данных)
│       └── resetAdminPassword.js  # Сброс пароля админа
├── frontend/
│   └── src/
│       ├── features/
│       │   ├── admin/         # Вкладки администратора
│       │   ├── auth/          # Вход / регистрация
│       │   ├── documents/     # Документы сотрудника
│       │   ├── moderator/     # Посещения для модератора
│       │   ├── operator/      # Дашборд сотрудника
│       │   ├── scan/          # QR-сканирование
│       │   └── tasks/         # Задания
│       ├── layout/            # Header, Sidebar, Layout
│       ├── api/               # RTK Query API
│       └── components/        # Общие компоненты
└── database/
    └── init.sql               # Схема БД + начальные данные
```
